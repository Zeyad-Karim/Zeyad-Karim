Co-designed a CLI/MCP-based malware-analysis workflow combining **VirusTotal, Ghidra, static/dynamic analysis, memory/timeline analysis, and PCAP evidence** to produce structured verdicts, IOCs, MITRE ATT&CK mappings, and incident-response outputs.
